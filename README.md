# OFL — Onyx Freedom License

**Maximum freedom. Minimal restrictions.**

The Onyx Freedom License (OFL) is an experimental permissive software license designed to maximize the freedom of software users, developers, and redistributors.

## Philosophy

OFL aims to give recipients broad freedom to:

- Use software for any purpose.
- Study, copy, modify, and redistribute software.
- Sell original or modified versions.
- Create proprietary or open-source forks.
- License their own contributions under different terms.
- Keep modifications private without an obligation to publish source code.
- Redistribute software without mandatory attribution or preservation of the original license text.

## No Copyleft

OFL does not require derivative works to use the same license, publish source code, or share modifications.

## Project Status

OFL is an experimental draft and has not undergone formal legal review or received approval from an open-source licensing organization.

**This draft is not a finalized, legally reviewed license.**
